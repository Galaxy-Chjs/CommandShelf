# CommandShelf v1.0.0

**Your commands, prompts and snippets — three seconds away.**

Press <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> anywhere, type two or three letters, press
<kbd>Enter</kbd>. The text is on your clipboard, the panel is gone, and focus is back in the window
you were working in. That round trip is the whole point; everything else exists so the round trip
has something good in it.

## What it does

- **Quick panel.** A global hotkey opens a frameless, always-on-top panel that searches as you type.
  <kbd>Enter</kbd> copies and dismisses. It hides on blur and remembers nothing between openings.
- **Template variables.** Anything in `{{braces}}` becomes a field you fill in before copying, with
  defaults pre-filled and a live preview of the final text:

  ```bash
  ssh -L {{local_port=8888}}:localhost:{{remote_port=8888}} {{server=user@10.0.0.12}} -N
  ```

- **Five kinds** — command, prompt, code snippet, link, path — each with its own colour, icon and
  default action, so a list stays scannable.
- **Search that fits the content.** English queries use SQLite FTS5 with prefix matching and BM25
  ranking; queries containing Chinese fall back to substring matching, because FTS5's tokenizer does
  not split Chinese words. Tags and collection names are searched too.
- **Collections, tags, favourites**, rename and merge, with a delete that is undoable from the toast.
- **Start at login**, silently to the tray — no window on every boot, just the hotkey.

## Your data

One SQLite file, WAL mode. No account, no network requests, no telemetry, no updater. Export
everything to readable JSON at any time; the path to the database is shown in Settings.

## Requirements

- Windows 10+, or a modern Linux desktop, or macOS 11+.
- Building from source needs Node.js 22.5+ (the app uses the built-in `node:sqlite`, so there is no
  native dependency to compile).

## Known limitations

- No code signing, so first launch warns on Windows and macOS.
- Linux and macOS builds are produced and smoke-checked by CI but have not been run on physical
  machines by the author; the Windows build has.
- Auto-start is registered through the operating system (the `Run` key on Windows) and is not
  supported on Linux, where the app says so instead of pretending.
